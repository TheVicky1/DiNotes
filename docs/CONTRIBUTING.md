# Contributing to DiNotes

Thank you for considering contributing to **DiNotes**! We welcome bug fixes, feature enhancements, documentation improvements, and UI refinements.

---

## Code of Conduct

Please help maintain a welcoming, respectful, and collaborative environment for all contributors.

---

## How to Contribute

### 1. Check Existing Issues
Search existing [GitHub Issues](https://github.com/TheVicky1/DiNotes/issues) before submitting new feature requests or bug reports.

### 2. Fork & Create a Branch
Fork the repository and create a descriptive feature branch:

```bash
git checkout -b feature/my-new-feature
```

### 3. Make & Test Your Changes
Make your code changes and verify build and lint status:

```bash
npm run lint
npm run build
```

### 4. Commit Conventions
Use structured commit messages:
- `feat: add graph node filtering by tag`
- `fix: correct pdfjs worker resolution`
- `docs: update getting started guide`

### 5. Submit a Pull Request
Push your branch to GitHub and open a Pull Request targeting `main`. Fill in the [Pull Request Template](../.github/PULL_REQUEST_TEMPLATE.md).
